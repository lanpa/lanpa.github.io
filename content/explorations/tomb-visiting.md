# 興福庄建塚紀念碑

小時候都是來萬隆掃墓，2010前後這區被市政府改建爲公園。剛好比較有空閒，想去看看變得如何。查了一下，這塊墓地叫興福庄，有個興福庄建塚紀念碑。

## 碑文與歷史資訊


{{< figure src="/images/exploration/xingfuzhuang/IMG_8616_watermarked.jpg" caption="紀念碑" >}}
{{< figure src="/images/exploration/xingfuzhuang/IMG_8615_watermarked.jpg" caption="紀念碑背面" >}}
{{< figure src="/images/exploration/xingfuzhuang/IMG_8617_watermarked.jpg" caption="簡介" >}}

> 本碑約建於1929年，為紀念當時有心人士集資購地供萬華、古亭地區窮苦人家安葬之用，興福庄與大直庄兩地，喪葬之用地約有三十餘甲規模大。興築依據碑文記載，係提供臺北市民建塚使用，昭和四年在臺北州允準捐金購地後，得到北市諸多鄉紳商戶（辜顯榮、陳天來、林柏壽、許丙等）捐款，並限於臺北市，並由增用市戶建碑紀念，由倪希昶撰文記載其事。
